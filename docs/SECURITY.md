# ตั้งค่าให้ปลอดภัยก่อนใช้งานจริง

ระบบนี้รับเงินจริงและเก็บเลขบัญชีธนาคารของร้านค้า อ่านทั้งหน้านี้ก่อนเปิดใช้กับเงินของใครก็ตาม

## ต้องตั้งเองทุกตัว ไม่มีค่าเริ่มต้นที่ใช้ได้

| ตัวแปร | ใช้ทำอะไร | ถ้าไม่ตั้ง |
|---|---|---|
| `MYSQL_ROOT_PASSWORD`, `DB_PASS` | ฐานข้อมูล | คอนเทนเนอร์ไม่ขึ้น |
| `ADMIN_PASSWORD` | สร้างบัญชีแอดมินตัวแรก | เข้าหน้าแอดมินไม่ได้เลย |
| `STRIPE_SECRET_KEY` | สร้าง QR รับชำระเงิน | ระบบไม่บูต |
| `STRIPE_WEBHOOK_SECRET` | ตรวจลายเซ็นของ webhook | webhook ตอบ 503 ทุกครั้ง สถานะรายการจะค้าง |
| `PUBLIC_BASE_URL` | ที่อยู่สาธารณะของระบบ | ลิงก์ในระบบชี้ผิดที่ |
| `PROVIDER_FEE_PERCENT` | ต้นทุนของผู้ให้บริการรับชำระเงิน | ใช้ 1.77 ซึ่งเป็นค่าที่วัดจาก Stripe ในไทย ตรวจกับสัญญาของคุณเอง |

ฝั่งเฟิร์มแวร์ต้องตั้งสองอย่างตอน build ไม่งั้นเครื่องจะติดต่ออะไรไม่ได้และรหัสช่างจะเป็นค่าเริ่มต้น

```
build_flags =
    -D BACKEND_BASE_URL='"https://your-server.example/api/"'
    -D MA_PIN='"<รหัสหกหลักของคุณ>"'
```

## ข้อควรระวังที่ต้องรู้

**การลงทะเบียนเครื่องเปิดกว้างโดยออกแบบ** — `/api/provision_register` รับแค่ MAC ไม่มีการยืนยันตัวตน
เพราะเครื่องใหม่ยังไม่มีกุญแจอะไรให้ใช้พิสูจน์ตัวเอง เครื่องที่ลงทะเบียนเข้ามาจะมีสถานะ **ปิด**
(`is_active = 0`) จนกว่าแอดมินจะเปิดให้ จึงสร้าง QR หรือรับเงินไม่ได้

แต่ถ้าใครรู้ที่อยู่เซิร์ฟเวอร์คุณ เขายิงคำขอลงทะเบียนเข้ามาได้เรื่อยๆ ควรวางหลัง reverse proxy
ที่จำกัดอัตราได้ และอย่าเปิดสวิตช์ให้เครื่องที่คุณไม่รู้จัก

**รหัสช่างอ่านได้จากไฟล์เฟิร์มแวร์เสมอ** — ใครถอด flash ออกไปอ่านก็เจอ เป็นการกันลูกค้าเผลอเข้า
ไม่ใช่การป้องกันคนที่ตั้งใจเจาะ อย่าใช้รหัสเดียวกับอย่างอื่น

**ระบบไม่เคยแตะเลขบัตรเครดิต** จึงไม่เข้าข่าย PCI-DSS แบบเต็ม แต่ถ้าจะต่อ API ของธนาคาร
ธนาคารจะมีชุดข้อกำหนดของตัวเองที่ต้องผ่านก่อน และการรับชำระเงินแทนผู้อื่นอาจเข้าข่ายธุรกิจ
ที่ต้องขออนุญาตในบางประเทศ — ตรวจกับที่ปรึกษากฎหมายในเขตของคุณ

**ระบบนี้ยังไม่เคยผ่านการตรวจสอบความปลอดภัยจากบุคคลภายนอก**

## เมื่อรับระบบต่อจากคนอื่น

หมุนความลับใหม่ทุกตัว เจ้าของเดิมเคยเห็นค่าเหล่านี้ทั้งหมด

- ค่าใน `.env` ทุกบรรทัด และรหัสผ่านบัญชีแอดมินทุกบัญชี
- token ของช่องทางแจ้งเตือนใน `alerts/env.alerts`
- `MA_PIN` — ต้อง build ใหม่แล้วส่ง OTA ให้ครบทุกเครื่อง
- กุญแจ SSH ของเซิร์ฟเวอร์
- `device_key` ของทุกเครื่องในตาราง `devices`
